디자인소통 · 소통 칼럼

핵심 답변

보기 좋은 마감과 실제 작동, 계약 범위와 미완료 항목을 나누어 확인하면 누락을 줄이기 쉽습니다.

이 글에서 살펴볼 내용

  1. 계약 자료와 현장을 대조합니다
  2. 실제 사용 동작을 확인합니다
  3. 잔여 항목을 목록으로 남깁니다
  4. 공사 계획에 적용해 보면

계약 자료와 현장을 대조합니다

최종 도면과 견적·자재 목록을 가져가 구역별로 확인하세요. 색과 제품, 설치 위치가 달라진 부분은 승인 기록과 함께 검토합니다.

실제 사용 동작을 확인합니다

문과 서랍을 열고 수전과 조명, 냉난방과 배수를 가동해 보세요. 제품과 설비에 필요한 점검은 담당자와 진행하고, 작동 조건과 결과를 기록합니다.

잔여 항목을 목록으로 남깁니다

위치와 사진, 필요한 조치와 담당·완료 예정일을 적습니다. 행정 절차와 사용 가능 여부, 대금 정산·인수인계는 각각 어떤 상태인지 구분해 확인하세요.

공사 계획에 적용해 보면

마감 흠집과 설비 미작동이 함께 발견되면 각각 위치·증상·담당자를 구분해 목록으로 남기세요. 눈에 잘 보이는 항목만 고치는 데 집중하지 않고, 실제 사용과 남은 행정·인수인계 상태까지 확인하기 좋습니다.

상담 전 확인사항

  • 최종 계약·승인 자료
  • 구역별 작동 점검
  • 잔여 항목·완료 일정
