핵심 답변

브랜드나 재료 이름만으로 판단하기보다 적용 부위의 요구 조건과 제품·구성에 맞는 증빙을 대조해야 합니다.

이 글에서 살펴볼 내용

  1. 필요한 성능을 먼저 확인합니다
  2. 실제 납품 사양과 대조합니다
  3. 변경 자재도 다시 확인합니다
  4. 공사 계획에 적용해 보면

필요한 성능을 먼저 확인합니다

건물의 용도·규모와 내부·외부 적용 위치에 따라 검토할 기준이 달라집니다. 모든 공간에 같은 마감재를 쓰면 된다는 방식으로 계획하지 않습니다.

실제 납품 사양과 대조합니다

시험·인정 자료가 어떤 제품과 두께, 구성과 적용 조건을 대상으로 하는지 확인하세요. 비슷한 이름의 다른 제품이나 단열재 하나의 성능을 전체 벽체 성능으로 확대하지 않습니다.

변경 자재도 다시 확인합니다

품절로 대체품을 쓸 때는 색과 가격뿐 아니라 필요한 성능 자료도 검토합니다. 납품 자료와 적용 위치를 준공 기록으로 정리하면 이후 보수 때도 기준을 확인하기 쉽습니다.

공사 계획에 적용해 보면

선택한 외장재의 자료가 다른 두께나 다른 복합 구성의 시험 결과라면 적용 가능성을 다시 확인해야 합니다. 제품 이름과 성능 등급만 받아두기보다 실제 납품 사양과 자료의 대상이 같은지 대조하는 것이 좋습니다.

상담 전 확인사항

  • 적용 부위 기준
  • 제품·구성 증빙
  • 납품·대체품 자료
